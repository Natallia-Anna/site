# GameHub - Игровой портал

## Описание
GameHub - это веб-приложение для игроков с системой регистрации, бесплатными играми, чатом и кошельком для покупки подписок.

## Функциональность
- Регистрация и авторизация пользователей
- Каталог бесплатных игр
- Чат между игроками
- Кошелек с системой подписок
- Адаптивный дизайн в голубых и зеленых тонах

## Запуск проекта

### Способ 1: Live Server в VS Code
1. Установите расширение "Live Server" в VS Code
2. Откройте папку проекта в VS Code
3. Правой кнопкой на `index.html` → "Open with Live Server"

### Способ 2: Python HTTP сервер
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

Затем откройте http://localhost:8000

Способ 3: Node.js сервер
# Установите http-server глобально
npm install -g http-server

# Запустите сервер
http-server -p 8000

Тестирование
Для запуска автотестов:

Откройте страницу games.html

Нажмите кнопку "🧪 Run Tests" в правом нижнем углу

Результаты тестов появятся в консоли браузера

Технологии
HTML5, CSS3, JavaScript (ES6+)

Local Storage для хранения данных

Адаптивный дизайн

CSS Grid и Flexbox

Структура данных
Пользователи хранятся в localStorage с полями:

username, email, password

balance (баланс)

subscription (тип подписки)

registrationDate

Примечания
Данные сохраняются в localStorage браузера

Для продакшн-версии рекомендуется добавить бэкенд

Изображения используются из открытых источников


## Запуск сайта

1. **Создайте папку проекта** и сохраните все файлы в соответствующей структуре
2. **Запустите через Live Server в VS Code** (рекомендуется):
   - Установите расширение "Live Server"
   - Правой кнопкой на `index.html` → "Open with Live Server"

3. **Или используйте любой статический сервер**:
   ```bash
   # Python 3
   python -m http.server 8000
   
   # Или с Node.js
   npx http-server
